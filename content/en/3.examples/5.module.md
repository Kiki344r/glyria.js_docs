## Overview

This page walks through a complete module built with the [Module SDK](/guide/modules) — an `economy` module with its own command, a public API for other modules, and a global middleware.

Scaffold the skeleton with:

```bash
npx glyria module create economy
```

## The manifest

```ts
// src/modules/economy/index.ts
export default defineModule({
  name: "economy",
  version: "1.0.0",
  description: "Coins, balances, and daily rewards",

  setup(ctx) {
    ctx.logger.info("economy loaded")

    // the returned object is the module's public API
    return {
      async getBalance(userId: string): Promise<number> {
        return (await ctx.store.get<number>(`balance:${userId}`)) ?? 0
      },
      async addBalance(userId: string, amount: number): Promise<number> {
        const balance = ((await ctx.store.get<number>(`balance:${userId}`)) ?? 0) + amount
        await ctx.store.set(`balance:${userId}`, balance)
        return balance
      },
    }
  },

  hooks: {
    onReady(ctx) {
      ctx.logger.info("bot is ready — economy online")
    },
  },
})
```

`ctx.store` is automatically scoped to the module (`module:economy:`) — no key collisions with other modules.

## A module command

Commands inside a module folder are auto-loaded like regular commands:

```ts
// src/modules/economy/commands/balance.ts
export default new GlyriaCommand()
  .setName("balance")
  .setDescription("Check your balance")
  .setCooldown("3s")
  .execute(async (ctx) => {
    const coins = await ctx.g.store.user.get<number>("balance") ?? 0
    await ctx.g.reply.primary(`💰 You have **${coins}** coins`)
  })
```

## Consuming the module from another module

```ts
// src/modules/shop/index.ts
export default defineModule({
  name: "shop",
  dependsOn: ["economy"],          // guarantees load order

  setup(ctx) {
    const economy = ctx.modules.get("economy")

    return {
      async buy(userId: string, price: number) {
        await economy.addBalance(userId, -price)
      },
    }
  },
})
```

### Typing the inter-module API

Augment the `GlyriaModules` interface so `ctx.modules.get("economy")` is fully typed:

```ts
// src/modules/economy/types.d.ts
declare module "@glyria/bot" {
  interface GlyriaModules {
    economy: {
      getBalance(userId: string): Promise<number>
      addBalance(userId: string, amount: number): Promise<number>
    }
  }
}
```

## A global middleware

A module can observe (or cancel) every command of the bot:

```ts
// src/modules/audit/index.ts
export default defineModule({
  name: "audit",

  hooks: {
    async beforeCommand(ctx, meta, next) {
      console.log(`[audit] /${meta.name.replaceAll(":", " ")}`)
      await next()                 // skip next() to cancel the command
    },
  },
})
```

## Testing the module

`createTestContext()` runs any handler without Discord:

```ts
// test/balance.test.ts
import "@glyria/bot/globals" // installs the runtime globals (GlyriaCommand, ...) under plain vitest
import { describe, it, expect } from "vitest"
import { createTestContext } from "@glyria/bot"
import balance from "../src/modules/economy/commands/balance.js"

describe("/balance", () => {
  it("replies with the balance", async () => {
    const ctx = createTestContext({ userId: "42" })

    await balance.getHandlers()[0]!.handler(ctx as never)

    expect(ctx.repliesText()[0]).toContain("coins")
  })
})
```

## Publishing to npm

A module is a normal npm package — `npm publish` is all it takes. Ship the same structure (`glyria.module.ts` or `index.ts` inside the package's `src/` or built `dist/` folder — not the bare package root — plus optional `commands/`, `events/`, `components/`), and consumers activate it in their config:

```ts
// glyria.config.ts
export default defineGlyriaConfig({
  modules: ["glyria-module-economy"],
  moduleConfig: {
    economy: { startingBalance: 100 },
  },
})
```
