## Overview

glyria.js ships a built-in visual generator, available as `ctx.g.canvas` (or the global `canvas`). It produces SVG in pure TypeScript — **zero native dependencies** — and rasterizes to PNG when an optional package is installed.

```ts
const card = await ctx.g.canvas
  .rankCard({ username: "Enzo", level: 12, xp: 340, xpNeeded: 500, rank: 3 })
  .attachment()

await ctx.g.reply.primary("Here's your rank!").file(card.data, card.name)
```

## Rank card

`ctx.g.canvas.rankCard(options)` renders a 934×282 card with avatar, level, rank and an XP progress bar:

| Option | Type | Description |
|---|---|---|
| `username` | `string` | Truncated at 20 chars |
| `level` | `number` | Displayed as "Level N" |
| `xp` / `xpNeeded` | `number` | Progress bar fill |
| `rank` | `number` | Displayed as "Rank #N" |
| `avatarUrl` | `string?` | Circular avatar — falls back to an initial letter |
| `accentColor` | `string?` | Default `#5865F2` |
| `backgroundColor` | `string?` | Default `#2b2d31` |

## Leaderboard

`ctx.g.canvas.leaderboard(options)` renders a titled list with 🥇🥈🥉 medals for the top three (max **10** entries, extras are dropped):

```ts
const board = await ctx.g.canvas
  .leaderboard({
    title: "XP Leaderboard",
    entries: [
      { rank: 1, username: "Enzo", value: "12,400 XP" },
      { rank: 2, username: "Kiki", value: "11,900 XP" },
      { rank: 3, username: "Nova", value: "9,300 XP" },
    ],
  })
  .attachment()
```

`accentColor` and `backgroundColor` are supported here too.

## Output formats

Both generators return a `GlyriaCanvasImage`:

| Method | Returns | Notes |
|---|---|---|
| `.svg()` | `string` | The raw SVG source |
| `.toBuffer()` | `Buffer` | SVG as a buffer |
| `.png()` | `Promise<Buffer>` | PNG — **throws** without a rasterizer |
| `.attachment()` | `Promise<{ data, name }>` | Ready for `.file(data, name)` |

## PNG rasterization

SVG generation always works. PNG output needs one optional package:

```bash
npm install @resvg/resvg-js   # recommended
# or
npm install sharp
```

`.attachment()` picks the best available format: PNG when a rasterizer is installed, otherwise it falls back to a `.svg` file.

::warning{title="Discord won't preview SVG"}
Without a rasterizer, `.attachment()` returns a `.svg` file — Discord uploads it fine but shows no image preview. Install `@resvg/resvg-js` for production bots.
::

## Full example

```ts
// src/commands/rank.ts
export default new GlyriaCommand()
  .setName("rank")
  .setDescription("Show your rank card")
  .execute(async (ctx) => {
    const xp = (await ctx.g.store.user.get<number>("xp")) ?? 0
    const level = Math.floor(xp / 500)

    const { data, name } = await ctx.g.canvas
      .rankCard({
        username: ctx.user.username,
        level,
        xp: xp % 500,
        xpNeeded: 500,
        rank: 3,
        avatarUrl: ctx.user.displayAvatarURL({ extension: "png" }),
      })
      .attachment()

    await ctx.g.reply.primary(`**${ctx.user.username}**, here's your progress:`).file(data, name)
  })
```

::tip{title="Outside a context"}
The `canvas` object is auto-imported and usable anywhere — `canvas.rankCard({...})` in a job or event works exactly the same.
::
