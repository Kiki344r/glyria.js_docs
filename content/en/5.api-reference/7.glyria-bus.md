## Overview

`GlyriaBus` is a typed pub/sub event bus with middleware support. It lets you communicate between different parts of your bot without coupling them together.

```ts
// src/utils/useBus.ts
type BotEvents = {
  userBanned: [guildId: string, userId: string, reason: string]
  levelUp: [userId: string, level: number]
}

export const useBus = new GlyriaBus<BotEvents>()
```

::tip{title="Auto-import"}
`GlyriaBus` is available globally — no import needed. Define your bus in `src/utils/` and it's auto-imported everywhere.
::

## Constructor

```ts
new GlyriaBus<Events>()
```

### Type parameter

`Events` is a record mapping event names to their payload types (as tuples):

```ts
type Events = {
  userBanned: [guildId: string, userId: string]
  levelUp: [userId: string, level: number]
}
```

## Methods

### `.on(event, listener)`

Register a listener for an event. Returns an unregister function.

```ts
const stop = useBus.on("userBanned", (guildId, userId) => {
  console.log(`${userId} banned from ${guildId}`)
})

// later
stop()
```

| Parameter  | Type                  | Description                         |
| ---------- | --------------------- | ----------------------------------- |
| `event`    | `keyof Events`        | Event name                          |
| `listener` | `Listener<Events[K]>` | Handler receiving the event payload |

**Returns** `() => void` — call it to remove the listener.

---

### `.once(event, listener)`

Register a listener that is removed after its first call. Returns an unregister function, like `.on()`.

```ts
useBus.once("userBanned", (guildId, userId, reason) => {
  console.log("first ban only")
})
```

---

### `.use(event, middleware)`

Register a middleware for an event. Middlewares and listeners share a single queue and run in pure registration order — a middleware registered after a `.on()` listener runs after it. A middleware receives the full payload plus `next` as last argument, and must call `next()` to continue the chain.

```ts
useBus.use("userBanned", async (guildId, userId, reason, next) => {
  console.log(`[middleware] ban received`)
  await next()
})
```

| Parameter    | Type                    | Description                          |
| ------------ | ----------------------- | ------------------------------------ |
| `event`      | `keyof Events`          | Event name                           |
| `middleware` | `Middleware<Events[K]>` | Handler with `next` as last argument |

---

### `.emit(event, ...args)`

Emit an event with typed arguments. Runs all middlewares and listeners in order.

```ts
await useBus.emit("userBanned", guildId, userId, reason)
```

| Parameter | Type           | Description         |
| --------- | -------------- | ------------------- |
| `event`   | `keyof Events` | Event name          |
| `...args` | `Events[K]`    | Typed event payload |

**Returns** `Promise<void>`

---

### `.off(event, middleware)`

Remove a specific middleware from an event. Only works with the exact function passed to `.use()` — a listener registered via `.on()` is wrapped internally, so `.off()` cannot remove it. Use the unsubscribe function returned by `.on()` instead.

```ts
useBus.off("userBanned", myMiddleware)
```

---

### `.clear(event)`

Remove all listeners and middlewares for an event.

```ts
useBus.clear("userBanned")
```

---

## Types

### `Middleware<T>`

```ts
type Middleware<T extends unknown[]> = (
  ...args: [...ctx: T, next: NextFunction]
) => unknown
```

### `Listener<T>`

```ts
type Listener<T extends unknown[]> = (...ctx: T) => unknown
```

### `NextFunction`

```ts
type NextFunction = () => void | Promise<void>
```

## Middleware chain

Middlewares and listeners run in registration order. Not calling `next()` stops the chain — subsequent middlewares and listeners won't run.

```ts
useBus.use("levelUp", async (userId, level, next) => {
  if (level < 5) return // stops here, listener never runs
  await next()
})

useBus.on("levelUp", (userId, level) => {
  console.log(`${userId} reached level ${level}`)
})
```

## globalBus

`globalBus` is a ready-made `GlyriaBus` singleton shipped with glyria.js. Unlike a bus you create yourself, it's shared across your whole project and every loaded module — making it the canonical place for framework-level lifecycle events.

```ts
globalBus.on("botReady", (client) => {
  console.log(`Logged in as ${client.user?.tag}`)
})
```

::tip{title="Auto-import"}
`globalBus` is available globally — no import needed.
::

### Events

| Event      | Payload          | Description                                                  |
| ---------- | ---------------- | ----------------------------------------------------------- |
| `botReady` | `[GlyriaClient]` | Emitted once, when the client is logged in and fully ready  |

`botReady` is the recommended entry point for initialization logic — especially inside [modules](/docs/guide/modules), where it replaces a `ready` event listener.

```ts
// inside a module's index.ts
globalBus.on("botReady", async (client) => {
  // safe to access client.user, guilds, etc.
  client.bus.on(Events.MessageCreate, (message) => {
    // ...
  })
})
```

::warning{title="globalBus vs your own bus"}
Use `globalBus` only for framework lifecycle events like `botReady`. For your own app events, create a dedicated typed `GlyriaBus` so its event names and payloads stay isolated and fully typed.
::
