## Overview

`ctx.g.canvas` generates dynamic images in pure TypeScript (SVG under the hood), with optional PNG rasterization through `@resvg/resvg-js` or `sharp` when either is installed. No native canvas dependency required.

```ts
export default new GlyriaCommand()
  .setName("rank")
  .setDescription("Show your rank card")
  .execute(async (ctx) => {
    const card = await ctx.g.canvas
      .rankCard({
        username: ctx.user.username,
        avatarUrl: ctx.user.displayAvatarURL(),
        level: 12,
        xp: 340,
        xpNeeded: 500,
        rank: 3,
      })
      .attachment()

    await ctx.g.reply.primary("Your rank").file(card.data, card.name)
  })
```

Both generators return a `GlyriaCanvasImage` handle — pick the output format from there.

## `canvas.rankCard(options)`

Renders a 934×282 rank card: avatar (or an accent-colored initial disc when `avatarUrl` is omitted), username, rank, level, and an XP progress bar.

### RankCardOptions

| Option            | Type     | Default     | Description                                       |
| ----------------- | -------- | ----------- | -------------------------------------------------- |
| `username`        | `string` | — (required)| Displayed name (truncated to 20 characters)        |
| `level`           | `number` | — (required)| Level shown top-right                              |
| `xp`              | `number` | — (required)| Current XP (progress bar numerator)                |
| `xpNeeded`        | `number` | — (required)| XP needed for the next level (progress bar clamps to 0–100%) |
| `rank`            | `number` | — (required)| Rank shown as `Rank #<n>`                          |
| `avatarUrl`       | `string` | —           | Avatar image URL; omitted → initial-letter placeholder |
| `accentColor`     | `string` | `#5865F2`   | Progress bar, avatar ring, and rank color          |
| `backgroundColor` | `string` | `#2b2d31`   | Card background                                    |

## `canvas.leaderboard(options)`

Renders a 700px-wide leaderboard with a title, accent underline, and zebra-striped rows. Ranks 1–3 get medal emojis (🥇 🥈 🥉), the rest `#<rank>`.

### LeaderboardOptions

| Option            | Type                | Default     | Description                                       |
| ----------------- | ------------------- | ----------- | -------------------------------------------------- |
| `title`           | `string`            | — (required)| Title shown above the rows                         |
| `entries`         | `LeaderboardEntry[]`| — (required)| Rows to display — **capped at 10 entries** (extra entries are dropped) |
| `accentColor`     | `string`            | `#5865F2`   | Underline and value color                          |
| `backgroundColor` | `string`            | `#2b2d31`   | Board background                                   |

### LeaderboardEntry

| Field      | Type     | Description                                     |
| ---------- | -------- | ------------------------------------------------ |
| `rank`     | `number` | Position — 1, 2, 3 render as medals              |
| `username` | `string` | Displayed name (truncated to 24 characters)      |
| `value`    | `string` | Right-aligned value (e.g. `"1,204 XP"`)          |

```ts
const board = await ctx.g.canvas
  .leaderboard({
    title: "XP Leaderboard",
    entries: top.map((u, i) => ({
      rank: i + 1,
      username: u.name,
      value: `${u.xp} XP`,
    })),
  })
  .attachment()

await ctx.g.reply.primary("Top members").file(board.data, board.name)
```

## GlyriaCanvasImage

The handle returned by both generators.

| Method          | Returns                                   | Description                                                          |
| --------------- | ----------------------------------------- | --------------------------------------------------------------------- |
| `.svg()`        | `string`                                  | The raw SVG source                                                     |
| `.toBuffer()`   | `Buffer`                                  | The SVG source as a UTF-8 buffer                                       |
| `.png()`        | `Promise<Buffer>`                         | PNG buffer — **requires** `@resvg/resvg-js` (recommended) or `sharp`; throws otherwise |
| `.attachment()` | `Promise<{ data: Buffer; name: string }>` | Ready for `.file(data, name)` — PNG (`*.png`) when a rasterizer is installed, SVG (`*.svg`) otherwise |

```ts
const image = ctx.g.canvas.rankCard({ ... })

image.svg()                 // "<svg xmlns=..."
await image.png()           // PNG Buffer (rasterizer required)
await image.attachment()    // { data, name: "rank-card.png" } or { ..., name: "rank-card.svg" }
```

::warning{title="PNG needs a rasterizer"}
`png()` throws when neither `@resvg/resvg-js` nor `sharp` is installed. `attachment()` never throws — it falls back to an `.svg` attachment, and the `.svg` extension makes the fallback visible (Discord won't preview SVG attachments). Install a rasterizer for production: `npm install @resvg/resvg-js`.
::

## `xmlEscape(s)`

Escapes `&`, `<`, `>`, `"`, and `'` for safe interpolation into SVG/XML. The built-in generators already escape all user-provided text; use it when building your own SVG.

```ts
xmlEscape(`Tom & "Jerry" <3`)
// => "Tom &amp; &quot;Jerry&quot; &lt;3"
```
