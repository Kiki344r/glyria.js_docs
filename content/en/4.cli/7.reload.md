## Usage

```bash
npm run build && npx glyria reload
```

`glyria reload` hot-swaps new code into your **running** production bot — without restarting the process and without dropping the gateway connection. Your bot never appears offline and no interaction is missed.

## What it does

When your bot logs in, it writes its process id to `.glyria/bot.pid`. `glyria reload` reads that file and sends the process a `SIGUSR2` signal. The bot then swaps everything in memory:

| Swapped in memory | Details |
|---|---|
| Config | `glyria.config.ts` is re-loaded |
| Commands | Handlers re-imported from `dist/` |
| Events | Listeners removed and re-registered |
| Components | Component handlers re-imported |
| Modules | Manifests re-imported, `setup()` re-run, hooks re-registered |

The gateway connection is untouched throughout — the swap is purely in-process.

## Discord re-registration

Commands are only re-registered on Discord's side **if they actually changed**. glyria.js diffs the new command bodies against the previous ones and:

- No difference → skips the Discord API call entirely (`No command changes, skipping Discord re-register`)
- Added / changed / removed commands → re-registers, logging a summary like `+ban ~ping -old`

So reloading after a pure logic change (no option or description edits) costs zero Discord API calls.

## Deploy workflow

```bash
# on your server
git pull
npx glyria build
npx glyria reload   # new code is live — bot never went offline
```

::warning{title="Not supported on Windows"}
`glyria reload` relies on the `SIGUSR2` POSIX signal, which does not exist on Windows. The command exits with an error on `win32`.
::

## Error cases

| Error | Meaning |
|---|---|
| `No .glyria/bot.pid found — is the bot running?` | The bot hasn't started (or was started from a different working directory) |
| `Invalid pid in .glyria/bot.pid` | The pid file is corrupted — restart the bot to rewrite it |
| `Could not signal pid <pid> — is the bot still running?` | The pid file is stale: the process it points to is gone |
