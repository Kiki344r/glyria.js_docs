## Usage

```bash
npx glyria studio           # http://localhost:4111
npx glyria studio -p 3000   # custom port (also --port)
```

Starts a local web UI where you can execute any command against a fake context and see a Discord-style preview of the reply — no bot token, no test server, no Discord client.

## What you get

**Command browser.** Every command in the sidebar, with its kind (`chat`, `user`, `message`) and guard badges — cooldown, required permissions, owner-only — visible at a glance.

**Auto-generated forms.** Selecting a command builds a form from its options: text inputs for `string`/`user`/`role`, number inputs for `integer`/`number`, checkboxes for `boolean`. Required options are marked, descriptions become placeholders. Subcommands get exactly the options of their own branch.

**Run against a fake context.** Hit Run (or `Ctrl+Enter`) and the handler executes in-process. Override the user id and guild id fields to test per-user or per-guild logic (empty fields fall back to the defaults `test-user` / `test-guild`).

**Embed V2 preview.** Replies render Discord-style: containers with their accent color, text with light markdown, separators, button rows with the right styles and disabled states, file attachments.

**Execution feedback.** Each run shows its execution time in milliseconds; if the handler throws, the full error stack is displayed in the output panel.

**Recordings tab.** Your 50 most recent [recorded interactions](/cli/replay) are listed; clicking one jumps to the command and prefills the form with the recorded options — replay a real user's exact input with one click.

## Live preview while you code

Commands are reloaded from disk **on every request**. Edit a handler, save, hit Run — the new code executes immediately. No restart, no rebuild, no browser refresh needed.

::warning{title="Fake context, not a real Discord session"}
Handlers run against a fake context: replies are captured and previewed, but raw discord.js API calls beyond replying (fetching members, sending to other channels, ...) may throw. Any such error is shown directly in the studio UI.
::
