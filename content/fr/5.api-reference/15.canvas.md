## Vue d'ensemble

`ctx.g.canvas` génère des images dynamiques en pur TypeScript (du SVG sous le capot), avec rastérisation PNG optionnelle via `@resvg/resvg-js` ou `sharp` quand l'un des deux est installé. Aucune dépendance canvas native requise.

```ts
export default new GlyriaCommand()
  .setName("rank")
  .setDescription("Show your rank card")
  .execute(async (ctx) => {
    const card = await ctx.g.canvas
      .rankCard({
        username: ctx.user.username,
        avatarUrl: ctx.user.displayAvatarURL(),
        level: 12,
        xp: 340,
        xpNeeded: 500,
        rank: 3,
      })
      .attachment()

    await ctx.g.reply.primary("Your rank").file(card.data, card.name)
  })
```

Les deux générateurs retournent un handle `GlyriaCanvasImage` — choisissez le format de sortie à partir de là.

## `canvas.rankCard(options)`

Rend une carte de rang de 934×282 : avatar (ou un disque avec l'initiale en couleur d'accent quand `avatarUrl` est omis), nom d'utilisateur, rang, niveau, et une barre de progression d'XP.

### RankCardOptions

| Option            | Type     | Défaut       | Description                                        |
| ----------------- | -------- | ------------ | --------------------------------------------------- |
| `username`        | `string` | — (requis)   | Nom affiché (tronqué à 20 caractères)               |
| `level`           | `number` | — (requis)   | Niveau affiché en haut à droite                     |
| `xp`              | `number` | — (requis)   | XP actuel (numérateur de la barre de progression)   |
| `xpNeeded`        | `number` | — (requis)   | XP nécessaire pour le niveau suivant (la barre est bornée à 0–100%) |
| `rank`            | `number` | — (requis)   | Rang affiché sous la forme `Rank #<n>`              |
| `avatarUrl`       | `string` | —            | URL de l'image d'avatar ; omise → placeholder avec l'initiale |
| `accentColor`     | `string` | `#5865F2`    | Couleur de la barre de progression, de l'anneau d'avatar et du rang |
| `backgroundColor` | `string` | `#2b2d31`    | Fond de la carte                                    |

## `canvas.leaderboard(options)`

Rend un classement de 700px de large avec un titre, un soulignement d'accent et des lignes en zébrures alternées. Les rangs 1–3 reçoivent des emojis de médailles (🥇 🥈 🥉), les autres `#<rank>`.

### LeaderboardOptions

| Option            | Type                | Défaut       | Description                                        |
| ----------------- | ------------------- | ------------ | --------------------------------------------------- |
| `title`           | `string`            | — (requis)   | Titre affiché au-dessus des lignes                  |
| `entries`         | `LeaderboardEntry[]`| — (requis)   | Lignes à afficher — **plafonné à 10 entrées** (les entrées en trop sont ignorées) |
| `accentColor`     | `string`            | `#5865F2`    | Couleur du soulignement et des valeurs              |
| `backgroundColor` | `string`            | `#2b2d31`    | Fond du tableau                                     |

### LeaderboardEntry

| Champ      | Type     | Description                                       |
| ---------- | -------- | -------------------------------------------------- |
| `rank`     | `number` | Position — 1, 2, 3 s'affichent en médailles         |
| `username` | `string` | Nom affiché (tronqué à 24 caractères)               |
| `value`    | `string` | Valeur alignée à droite (ex. `"1,204 XP"`)          |

```ts
const board = await ctx.g.canvas
  .leaderboard({
    title: "XP Leaderboard",
    entries: top.map((u, i) => ({
      rank: i + 1,
      username: u.name,
      value: `${u.xp} XP`,
    })),
  })
  .attachment()

await ctx.g.reply.primary("Top members").file(board.data, board.name)
```

## GlyriaCanvasImage

Le handle retourné par les deux générateurs.

| Méthode         | Retourne                                  | Description                                                            |
| --------------- | ----------------------------------------- | ----------------------------------------------------------------------- |
| `.svg()`        | `string`                                  | La source SVG brute                                                      |
| `.toBuffer()`   | `Buffer`                                  | La source SVG en buffer UTF-8                                            |
| `.png()`        | `Promise<Buffer>`                         | Buffer PNG — **nécessite** `@resvg/resvg-js` (recommandé) ou `sharp` ; lève une exception sinon |
| `.attachment()` | `Promise<{ data: Buffer; name: string }>` | Prêt pour `.file(data, name)` — PNG (`*.png`) quand un rastériseur est installé, SVG (`*.svg`) sinon |

```ts
const image = ctx.g.canvas.rankCard({ ... })

image.svg()                 // "<svg xmlns=..."
await image.png()           // Buffer PNG (rastériseur requis)
await image.attachment()    // { data, name: "rank-card.png" } ou { ..., name: "rank-card.svg" }
```

::warning{title="Le PNG nécessite un rastériseur"}
`png()` lève une exception quand ni `@resvg/resvg-js` ni `sharp` n'est installé. `attachment()` ne lève jamais d'exception — il se rabat sur une pièce jointe `.svg`, et l'extension `.svg` rend le repli visible (Discord ne prévisualise pas les pièces jointes SVG). Installez un rastériseur pour la production : `npm install @resvg/resvg-js`.
::

## `xmlEscape(s)`

Échappe `&`, `<`, `>`, `"` et `'` pour une interpolation sûre dans du SVG/XML. Les générateurs intégrés échappent déjà tout texte fourni par l'utilisateur ; utilisez-le quand vous construisez votre propre SVG.

```ts
xmlEscape(`Tom & "Jerry" <3`)
// => "Tom &amp; &quot;Jerry&quot; &lt;3"
```
