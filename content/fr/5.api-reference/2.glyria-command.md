## Vue d'ensemble

`GlyriaCommand` est le builder utilisé pour définir des commandes slash Discord. Chaque fichier dans `src/commands/` doit exporter une instance de `GlyriaCommand` par défaut.

```ts id="cmd1"
// src/commands/ping.ts
export default new GlyriaCommand()
  .setName("ping")
  .setDescription("Pong!")
  .execute(async (ctx) => {
    await ctx.reply({ content: "Pong!" })
  })
```

`GlyriaCommand` est disponible globalement — aucun import nécessaire.
\::

## GlyriaCommand

### Méthodes

| Méthode                   | Retour | Description                                   |
| ------------------------- | ------ | --------------------------------------------- |
| `.setName(name)`          | `this` | Définit le nom de la commande                 |
| `.setDescription(desc)`   | `this` | Définit la description de la commande         |
| `.setPermissions(perms)`  | `this` | Restreint la commande à certaines permissions |
| `.setMetaData(meta)`      | `this` | Ajoute des métadonnées personnalisées         |
| `.addStringOption(fn)`    | `this` | Ajoute une option string                      |
| `.addBooleanOption(fn)`   | `this` | Ajoute une option booléenne                   |
| `.addIntegerOption(fn)`   | `this` | Ajoute une option entière                     |
| `.addNumberOption(fn)`    | `this` | Ajoute une option numérique                   |
| `.addUserOption(fn)`      | `this` | Ajoute une option utilisateur                 |
| `.addRoleOption(fn)`      | `this` | Ajoute une option rôle                        |
| `.addSubCommand(fn)`      | `this` | Ajoute une sous-commande                      |
| `.addSubCommandGroup(fn)` | `this` | Ajoute un groupe de sous-commandes            |
| `.execute(handler)`       | `this` | Définit le handler d’exécution                |

---

## `.setPermissions()`

Restreint l’utilisation de la commande aux membres ayant certaines permissions Discord. Accepte un `bigint`, `number` ou `string`.

```ts id="perm1"
export default new GlyriaCommand()
  .setName("ban")
  .setDescription("Bannir un utilisateur")
  .setPermissions(djs.PermissionsBitField.Flags.BanMembers)
  .execute(async (ctx) => {
    // seuls les membres ayant la permission BanMembers peuvent utiliser cette commande
  })
```

---

## `.setMetaData()`

Ajoute des métadonnées personnalisées à la commande. Accepte un objet libre — Glyria le stocke tel quel sans l’interpréter.

```ts id="meta1"
export default new GlyriaCommand()
  .setName("ban")
  .setDescription("Bannir un utilisateur")
  .setMetaData({
    category: "moderation",
    cooldown: 5000,
    premium: false,
    guildOnly: true,
  })
  .execute(async (ctx) => {
    // votre logique ici
  })
```

Les métadonnées sont accessibles à l’exécution via `useCommands()` :

```ts id="meta2"
const commands = useCommands()

// [
//   {
//     name: "ban",
//     description: "Bannir un utilisateur",
//     meta: {
//       category: "moderation",
//       cooldown: 5000,
//       premium: false,
//       guildOnly: true
//     }
//   }
// ]
```

`useCommands()` est disponible globalement — aucun import nécessaire. Le registre est automatiquement rempli au démarrage du bot.

## CommandOption

Reçu en argument dans les callbacks `add*Option`.

### Méthodes

| Méthode                 | Retour | Description                     |
| ----------------------- | ------ | ------------------------------- |
| `.setName(name)`        | `this` | Définit le nom de l’option      |
| `.setDescription(desc)` | `this` | Définit la description          |
| `.setRequired(bool)`    | `this` | Définit si l’option est requise |

### Exemple

```ts id="opt1"
.addStringOption((option) =>
  option
    .setName("reason")
    .setDescription("Raison du bannissement")
    .setRequired(false)
)
```

## GlyriaSubCommand

Reçu en argument dans `.addSubCommand()`.

### Méthodes

| Méthode                 | Retour | Description                        |
| ----------------------- | ------ | ---------------------------------- |
| `.setName(name)`        | `this` | Définit le nom de la sous-commande |
| `.setDescription(desc)` | `this` | Définit la description             |
| `.addStringOption(fn)`  | `this` | Ajoute une option string           |
| `.addBooleanOption(fn)` | `this` | Ajoute une option booléenne        |
| `.addIntegerOption(fn)` | `this` | Ajoute une option entière          |
| `.addNumberOption(fn)`  | `this` | Ajoute une option numérique        |
| `.addUserOption(fn)`    | `this` | Ajoute une option utilisateur      |
| `.addRoleOption(fn)`    | `this` | Ajoute une option rôle             |
| `.execute(handler)`     | `this` | Définit le handler                 |

### Exemple

```ts id="sub1"
.addSubCommand((cmd) =>
  cmd
    .setName("ban")
    .setDescription("Bannir un utilisateur")
    .addUserOption((option) =>
      option
        .setName("user")
        .setDescription("Utilisateur à bannir")
        .setRequired(true)
    )
    .execute(async (ctx) => {
      // gérer le bannissement
    })
)
```

## GlyriaSubCommandGroup

Reçu en argument dans `.addSubCommandGroup()`.

### Méthodes

| Méthode                 | Retour | Description              |
| ----------------------- | ------ | ------------------------ |
| `.setName(name)`        | `this` | Définit le nom du groupe |
| `.setDescription(desc)` | `this` | Définit la description   |
| `.addSubCommand(fn)`    | `this` | Ajoute une sous-commande |

### Exemple

```ts id="group1"
.addSubCommandGroup((group) =>
  group
    .setName("config")
    .setDescription("Commandes de configuration")
    .addSubCommand((cmd) =>
      cmd
        .setName("logs")
        .setDescription("Configurer les logs")
        .addBooleanOption((option) =>
          option
            .setName("enabled")
            .setDescription("Activer les logs")
            .setRequired(true)
        )
        .execute(async (ctx) => {
          // gestion configuration logs
        })
    )
)
```
