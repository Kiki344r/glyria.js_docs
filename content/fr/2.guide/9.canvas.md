## Vue d'ensemble

glyria.js embarque un générateur visuel intégré, disponible via `ctx.g.canvas` (ou le global `canvas`). Il produit du SVG en pur TypeScript — **zéro dépendance native** — et rasterise en PNG quand un package optionnel est installé.

```ts
const card = await ctx.g.canvas
  .rankCard({ username: "Enzo", level: 12, xp: 340, xpNeeded: 500, rank: 3 })
  .attachment()

await ctx.g.reply.primary("Here's your rank!").file(card.data, card.name)
```

## Rank card

`ctx.g.canvas.rankCard(options)` rend une carte de 934×282 avec avatar, niveau, rang et une barre de progression d'XP :

| Option | Type | Description |
|---|---|---|
| `username` | `string` | Tronqué à 20 caractères |
| `level` | `number` | Affiché comme "Level N" |
| `xp` / `xpNeeded` | `number` | Remplissage de la barre de progression |
| `rank` | `number` | Affiché comme "Rank #N" |
| `avatarUrl` | `string?` | Avatar circulaire — se rabat sur une lettre initiale |
| `accentColor` | `string?` | Défaut `#5865F2` |
| `backgroundColor` | `string?` | Défaut `#2b2d31` |

## Leaderboard

`ctx.g.canvas.leaderboard(options)` rend une liste titrée avec des médailles 🥇🥈🥉 pour les trois premiers (max **10** entrées, les surnuméraires sont ignorées) :

```ts
const board = await ctx.g.canvas
  .leaderboard({
    title: "XP Leaderboard",
    entries: [
      { rank: 1, username: "Enzo", value: "12,400 XP" },
      { rank: 2, username: "Kiki", value: "11,900 XP" },
      { rank: 3, username: "Nova", value: "9,300 XP" },
    ],
  })
  .attachment()
```

`accentColor` et `backgroundColor` sont aussi supportés ici.

## Formats de sortie

Les deux générateurs retournent une `GlyriaCanvasImage` :

| Méthode | Retourne | Notes |
|---|---|---|
| `.svg()` | `string` | La source SVG brute |
| `.toBuffer()` | `Buffer` | Le SVG sous forme de buffer |
| `.png()` | `Promise<Buffer>` | PNG — **lève une erreur** sans rasterizer |
| `.attachment()` | `Promise<{ data, name }>` | Prêt pour `.file(data, name)` |

## Rasterisation PNG

La génération SVG fonctionne toujours. La sortie PNG nécessite un package optionnel :

```bash
npm install @resvg/resvg-js   # recommandé
# ou
npm install sharp
```

`.attachment()` choisit le meilleur format disponible : PNG quand un rasterizer est installé, sinon il se rabat sur un fichier `.svg`.

::warning{title="Discord ne prévisualise pas le SVG"}
Sans rasterizer, `.attachment()` retourne un fichier `.svg` — Discord l'uploade sans problème mais n'affiche aucun aperçu d'image. Installez `@resvg/resvg-js` pour les bots en production.
::

## Exemple complet

```ts
// src/commands/rank.ts
export default new GlyriaCommand()
  .setName("rank")
  .setDescription("Show your rank card")
  .execute(async (ctx) => {
    const xp = (await ctx.g.store.user.get<number>("xp")) ?? 0
    const level = Math.floor(xp / 500)

    const { data, name } = await ctx.g.canvas
      .rankCard({
        username: ctx.user.username,
        level,
        xp: xp % 500,
        xpNeeded: 500,
        rank: 3,
        avatarUrl: ctx.user.displayAvatarURL({ extension: "png" }),
      })
      .attachment()

    await ctx.g.reply.primary(`**${ctx.user.username}**, here's your progress:`).file(data, name)
  })
```

::tip{title="En dehors d'un contexte"}
L'objet `canvas` est auto-importé et utilisable partout — `canvas.rankCard({...})` dans un job ou un event fonctionne exactement pareil.
::
