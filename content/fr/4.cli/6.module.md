## Utilisation

```bash
npx glyria module create <name>
npx glyria module list
```

Les modules sont des fonctionnalités autonomes — un manifeste, plus leurs propres commandes, événements et composants. Lisez le [guide des modules](/guide/modules) pour la vue complète.

## `module create`

```bash
npx glyria module create economy
```

Génère un module prêt à l'emploi :

```
src/modules/economy/
  index.ts        # manifeste du module (defineModule)
  commands/
    economy.ts    # commande d'exemple — chargée automatiquement
```

Le `index.ts` généré est un manifeste `defineModule` avec tout de pré-câblé :

| Partie | Description |
|---|---|
| `name`, `version`, `description` | Identité du module (démarre à `0.1.0`) |
| `setup(ctx)` | S'exécute au chargement — l'objet retourné est l'API publique du module, appelable depuis les autres modules via `ctx.modules.get("economy")` |
| `hooks.onReady` | S'exécute quand le bot est prêt |
| `dependsOn`, `config`, `beforeCommand` | Exemples commentés pour les dépendances, le schéma de config et le middleware global |

Le dossier `commands/` fonctionne exactement comme `src/commands/` — tout ce que vous y déposez est chargé automatiquement, hot reloadé en dev, et scopé au module.

::warning{title="Les modules existants ne sont jamais touchés"}
Si `src/modules/<name>` existe déjà, `module create` se termine avec une erreur au lieu d'écraser quoi que ce soit.
::

## `module list`

```bash
npx glyria module list
```

Découvre et affiche chaque module que votre bot chargerait :

- **Modules locaux** depuis `src/modules/`
- **Modules npm** déclarés dans le tableau `modules` de `glyria.config.ts`

Pour chaque module, vous obtenez son nom, sa version, ses dépendances (`dependsOn`) et ses hooks enregistrés :

```
  ✔ economy v0.1.0 hooks: onReady
  ✔ moderation v1.2.0 deps: economy hooks: onReady, beforeCommand
```

Les entrées invalides (fichiers qui n'exportent pas un manifeste `defineModule`) sont signalées par `✖ <invalid>` avec leur chemin source, pour repérer facilement un module cassé avant qu'il n'atteigne la production.
