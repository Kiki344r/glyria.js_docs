## Utilisation

```bash
npm run start
# ou
npx glyria start
```

## Ce que ça fait

`glyria start` lance votre bot compilé en mode production. Il exécute `dist/index.js` avec le runtime glyria.js injecté automatiquement.

::warning{title="Build requis"}
`glyria start` nécessite un build compilé. Si `dist/index.js` est introuvable, il se termine avec une erreur.

Exécutez toujours `glyria build` avant `glyria start`.
::

## Workflow de production

```bash
# 1. compiler
npm run build

# 2. démarrer
npm run start
```

## Différence avec le mode dev

| | `glyria dev` | `glyria start` |
|---|---|---|
| Source | `src/` (TypeScript) | `dist/` (JavaScript) |
| Hot reload | ✅ | ❌ |
| Build requis | ❌ | ✅ |
| Cas d'usage | Développement | Production |
