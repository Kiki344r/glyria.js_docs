## Utilisation

```bash
npx glyria studio           # http://localhost:4111
npx glyria studio -p 3000   # port personnalisé (aussi --port)
```

Démarre une interface web locale où vous pouvez exécuter n'importe quelle commande contre un faux contexte et voir un aperçu façon Discord de la réponse — pas de token de bot, pas de serveur de test, pas de client Discord.

## Ce que vous obtenez

**Navigateur de commandes.** Chaque commande dans la barre latérale, avec son type (`chat`, `user`, `message`) et ses badges de gardes — cooldown, permissions requises, réservée au propriétaire — visibles d'un coup d'œil.

**Formulaires auto-générés.** Sélectionner une commande construit un formulaire à partir de ses options : champs texte pour `string`/`user`/`role`, champs numériques pour `integer`/`number`, cases à cocher pour `boolean`. Les options obligatoires sont marquées, les descriptions deviennent des placeholders. Les sous-commandes reçoivent exactement les options de leur propre branche.

**Exécution contre un faux contexte.** Cliquez sur Run (ou `Ctrl+Enter`) et le handler s'exécute in-process. Surchargez les champs user id et guild id pour tester la logique par utilisateur ou par serveur — laissez le guild id vide pour simuler un DM.

**Aperçu Embed V2.** Les réponses sont rendues façon Discord : containers avec leur couleur d'accent, texte avec markdown léger, séparateurs, rangées de boutons avec les bons styles et états désactivés, pièces jointes.

**Retour d'exécution.** Chaque exécution affiche son temps d'exécution en millisecondes ; si le handler lève une exception, la stack d'erreur complète s'affiche dans le panneau de sortie.

**Onglet Recordings.** Vos 50 [interactions enregistrées](/cli/replay) les plus récentes sont listées ; en cliquer une ouvre la commande et préremplit le formulaire avec les options enregistrées — rejouez l'entrée exacte d'un utilisateur réel en un clic.

## Aperçu en direct pendant que vous codez

Les commandes sont rechargées depuis le disque **à chaque requête**. Modifiez un handler, sauvegardez, cliquez sur Run — le nouveau code s'exécute immédiatement. Pas de redémarrage, pas de rebuild, pas de rafraîchissement du navigateur.

::warning{title="Faux contexte, pas une vraie session Discord"}
Les handlers s'exécutent contre un faux contexte : les réponses sont capturées et prévisualisées, mais les appels bruts à l'API discord.js au-delà de la réponse (récupérer des membres, envoyer dans d'autres salons, ...) peuvent lever une exception. Toute erreur de ce type est affichée directement dans l'interface du studio.
::
