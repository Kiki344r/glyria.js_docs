## Utilisation

```bash
npm run build
# ou
npx glyria build
```

## Ce que ça fait

`glyria build` prépare votre bot pour la production en deux étapes :

1. **Génère les auto-imports** — exécute `glyria generate` pour mettre à jour `.glyria/imports.d.ts`
2. **Compile TypeScript** — exécute `tsc` et dépose les fichiers compilés dans `dist/`

## Résultat

Après un build réussi, votre projet contiendra un dossier `dist/` qui reflète la structure de `src/` :

```
dist/
  commands/
    ping.js
  events/
    ready.js
  utils/
    useDatabase.js
  index.js
```

## Erreurs

Si la compilation TypeScript échoue, `glyria build` se termine avec un code non-zéro et affiche les erreurs du compilateur. Corrigez les erreurs signalées et relancez `glyria build`.

::tip{title="Toujours builder avant de déployer"}
Exécutez `glyria build` avant de démarrer votre bot en production. `glyria start` exécute le fichier compilé `dist/index.js` — pas votre source TypeScript.
::
