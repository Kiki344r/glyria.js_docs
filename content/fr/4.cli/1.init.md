## Utilisation

```bash
npx glyria init
```

Exécutez cette commande dans un dossier vide pour initialiser un nouveau projet glyria.js.

## Ce que ça fait

`glyria init` configure tout ce dont vous avez besoin pour commencer à construire votre bot :

**Crée la structure de dossiers**
```
src/
  commands/
    ping.ts
  events/
  utils/
.glyria/
```

**Génère les fichiers de configuration**

| Fichier | Description |
|---|---|
| `tsconfig.json` | Configuration TypeScript préconfigurée |
| `glyria.config.ts` | Fichier de configuration glyria.js |
| `.env` | Variables d'environnement (token) |
| `.gitignore` | Ignore `node_modules/`, `dist/`, `.env`, `.glyria/` |

**Met à jour `package.json`**

Ajoute automatiquement les scripts suivants :

```json
{
  "scripts": {
    "dev": "glyria dev",
    "build": "glyria build",
    "start": "glyria start",
    "generate": "glyria generate"
  }
}
```

**Installe les dépendances**

```
@glyria/bot
typescript
@types/node
tsx
```

**Génère les auto-imports**

Exécute `glyria generate` automatiquement à la fin — vos globals sont immédiatement disponibles.

## Après l'init

Renseignez votre `.env` avec le token de votre bot :

```bash
TOKEN=your_bot_token_here
```

Puis démarrez votre bot :

```bash
npm run dev
```

::tip{title="Les fichiers existants ne sont jamais écrasés"}
`glyria init` ignore tout fichier déjà existant — `tsconfig.json`, `.env`, `glyria.config.ts`, etc. Peut être exécuté sans risque dans un projet existant.
::
