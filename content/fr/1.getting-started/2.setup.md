## Prérequis

- **Node.js** 22.x ou supérieur
- **npm** 10.x ou supérieur
- **TypeScript** 6.x ou supérieur

## Installation

Installez `@glyria/bot` dans votre projet :

```bash
npm install @glyria/bot
```

## Initialiser votre projet

Une fois installé, exécutez la commande `init` pour générer votre bot :

```bash
npx glyria init
```

Cela générera la structure suivante :

```txt
your-bot/
  src/
    commands/
    events/
    utils/
    index.ts
  .glyria/
    imports.d.ts
  .env
  .gitignore
  tsconfig.json
  glyria.config.ts
  package.json
```

## Configurer votre bot

Remplissez votre fichier `.env` avec le token de votre bot :

```bash
TOKEN=your_bot_token_here
```

::tip{title="Où trouver votre token ?"}
Rendez-vous sur le [Discord Developer Portal](https://discord.com/developers/applications), sélectionnez votre application, puis **Bot** → **Reset Token**.
::

## Démarrer votre bot

```bash
# développement (hot reload)
npm run dev

# production
npm run build
npm run start
```

::info{title="Auto-imports"}
glyria.js injecte automatiquement tous les utilitaires du framework (`GlyriaClient`, `command`, `embedV2`...) en tant que variables globales — aucun import requis dans vos fichiers de commandes.
::
