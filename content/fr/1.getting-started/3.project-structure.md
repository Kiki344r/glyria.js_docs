Après avoir exécuté `npx glyria init`, votre projet ressemblera à ceci :

```txt
your-bot/
  src/
    commands/
    events/
    utils/
    index.ts
  .glyria/
    imports.d.ts
  .env
  .gitignore
  tsconfig.json
  glyria.config.ts
  package.json
```

## src/

Le dossier principal contenant le code source de votre bot.

### src/commands/

Toutes vos commandes slash se trouvent ici. glyria.js analyse ce dossier récursivement au démarrage et enregistre automatiquement chaque fichier.

```txt
src/commands/
  ping.ts
  moderation/
    ban.ts
    kick.ts
  config/
    logs.ts
```

::tip{title="Sous-dossiers comme catégories"}
Les sous-dossiers servent uniquement à l'organisation — chaque fichier `.ts`, peu importe sa profondeur, est chargé comme une commande.
::

### src/events/

Les écouteurs d'événements Discord. Chaque fichier gère un ou plusieurs événements discord.js.

### src/utils/

Fonctions utilitaires et composables. Les fichiers placés ici sont automatiquement disponibles globalement grâce aux auto-imports — aucun import nécessaire.

```ts
// src/utils/useDatabase.ts
export const useDatabase = () => {
  // ...
}

// src/commands/ping.ts — aucun import requis
const db = useDatabase()
```

### src/index.ts

Le point d'entrée de votre bot. Minimaliste par conception :

```ts
const client = new GlyriaClient({
  intents: [GatewayIntentBits.Guilds]
})

await client.login()
```

## .glyria/

Généré automatiquement par glyria.js. Contient les fichiers de déclarations TypeScript pour les auto-imports.

::warning{title="Ne pas modifier"}
Ce dossier est régénéré à chaque exécution de `glyria generate` ou `glyria dev`. Toutes les modifications manuelles seront écrasées.
::

## .env

Variables d'environnement de votre bot. glyria.js charge automatiquement ce fichier au démarrage.

```bash
TOKEN=your_bot_token_here
```

## glyria.config.ts

Configuration globale de votre bot — thème, paramètres d'embed par défaut, et plus encore.

```ts
export default defineConfig({
  theme: {
    color: 0x5865F2,
    footer: { text: "Mon Bot" },
    timestamp: true,
  }
})
```

## tsconfig.json

Préconfiguré par `npx glyria init`. Inclut le dossier `.glyria/` pour la résolution des types des auto-imports.
